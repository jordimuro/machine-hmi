Necesito que desarrolles "machine-hmi-edge", una aplicación HMI web industrial que se ejecutará en Raspberry Pi 3 (ARMv7) para monitorizar y controlar un PLC vía OPC UA.

ARQUITECTURA GENERAL:
- Backend: Node.js + Express con WebSocket
- Frontend: React + Vite (SPA)
- Protocolo industrial: OPC UA (cliente)
- Base de datos: SQLite para históricos
- Despliegue: Backend como servicio systemd, frontend como archivos estáticos servidos por Express

REQUISITOS FUNCIONALES:

1. BACKEND (Node.js + Express):

Estructura de módulos:
```

├── src/
│   ├── server.js              # Punto de entrada
│   ├── config/
│   │   └── index.js           # Carga de .env

```

MODELOS DE DATOS:
```typescript
// TagValue
{
  name: string,           // "MachineSpeed"
  value: number | boolean | string,
  quality: "good" | "bad" | "uncertain",
  timestamp: number       // ms epoch
}

// AlarmEntry
{
  id: string,            // "ALM_OVERTEMP"
  active: boolean,
  message: string,
  since: number          // ms epoch
}

// HistorySample
{
  timestamp: number,
  data: {
    [tagName: string]: number
  }
}
```

API REST (todas bajo /api):

- GET /api/tags → Lista todos los tags actuales
- GET /api/tags/:name → Tag específico
- POST /api/cmd → Enviar comando (requiere rol maintenance)
  Body: { command: "START"|"STOP"|"RESET_ALARMS"|"SET_SETPOINT", params?: {...} }
- GET /api/alarms → Lista alarmas activas
- GET /api/history?tag=X&from=...&to=... → Histórico
- POST /api/login → Body: { pin: "1234" } → Response: { token, role }
- GET /api/me → Response: { role } (requiere token)

WebSocket (/ws):
- Autenticación vía token en query string o primer mensaje
- Mensajes servidor→cliente:
  * { type: "tag_update", payload: TagValue }
  * { type: "alarm_update", payload: AlarmEntry }
- Implementar heartbeat cada 30s

OPC UA:
- Cliente persistente con reconexión automática (backoff exponencial)
- Configuración de tags vía archivo JSON:
```json
{
  "pollingRateMs": 1000,
  "tags": {
    "MachineSpeed": { "nodeId": "ns=2;s=Machine.Speed", "loggable": true },
    "TemperatureZone1": { "nodeId": "ns=2;s=Heater.Zone1.Temperature", "loggable": true },
    "Alarm_Overtemp": { "nodeId": "ns=2;s=Alarms.Overtemp", "loggable": false, "alarm": true }
  }
}
```
- Lectura cíclica: actualiza tagStore y emite cambios por WebSocket
- Escritura: valida rol y límites antes de escribir al PLC
- Histórico: cada LOG_INTERVAL_MS guarda tags "loggable" en SQLite (retención 24h)

Autenticación:
- JWT con rol (operator/maintenance)
- Middleware que inyecta req.user = { role }
- Endpoints de escritura requieren maintenance

3. DESPLIEGUE:

Scripts (añadir a package.json):
```bash
# build-frontend.sh
cd frontend && npm run build && cd ..

# deploy-rpi.sh (ejemplo con rsync)
rsync -avz --delete backend/ pi@192.168.1.50:/opt/machine-hmi-backend/
rsync -avz --delete frontend/dist/ pi@192.168.1.50:/opt/machine-hmi-frontend/dist/
ssh pi@192.168.1.50 "sudo systemctl restart machine-hmi"
```

Servicio systemd (machine-hmi.service):
```ini
[Unit]
Description=Machine HMI Edge Service
After=network.target

[Service]
Type=simple
User=pi
WorkingDirectory=/opt/machine-hmi-backend
ExecStart=/usr/bin/node server.js
Restart=always
RestartSec=10
Environment=NODE_ENV=production

[Install]
WantedBy=multi-user.target
```
